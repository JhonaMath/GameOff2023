## 📖 About The Game

**Dungeon Survivor** is an intense action-packed dungeon crawler created for the **GitHub GameOff 2023** game jam. Dive into a dark dungeon filled with relentless enemies, upgrade your magical abilities, and survive waves of monsters culminating in an epic boss battle!

The game was developed in **one month** as part of the GameOff 2023 challenge, embracing the game jam spirit of creativity and rapid development.

---

## ✨ Key Features

- 🎯 **Dynamic Combat System**: Wield powerful magic weapons with cone-shaped attacks and devastating explosions
- 🧙 **Progressive Leveling**: Gain experience, level up, and choose between powerful stat upgrades
- 👾 **Multiple Enemy Types**: Face increasingly challenging enemies with unique behaviors
- 🐉 **Epic Boss Fight**: Survive 5 minutes to face a multi-phase boss encounter with intense music
- 💫 **Mana Management**: Balance your mana consumption and regeneration for optimal combat
- 📊 **Stat System**: Customize your character with upgrades including:
  - Life and Life Regeneration
  - Mana and Mana Regeneration
  - Movement Speed
  - Magic Range and Power
  - Explosion Range, Strength, and Cooldown
  - Experience Multiplier
  - Magic Cost Reduction

## 🎮 How to Play

### Controls

| Action | Control |
|--------|---------|
| **Move** | `WASD` or `Arrow Keys` |
| **Magic Cone Attack** | Hold `Left Mouse Button` |
| **Explosion Attack** | `Right Mouse Button` |
| **Pause** | `ESC` |

### Gameplay Tips

1. **Survive and Level Up**: Defeat enemies to gain experience and level up your character
2. **Choose Wisely**: Each level offers two random stat upgrades - choose based on your playstyle
3. **Manage Mana**: Your cone attack drains mana. Balance offense with regeneration time
4. **Use Explosions Strategically**: The explosion attack has a cooldown but deals massive area damage
5. **Survive 5 Minutes**: The epic boss fight begins at the 5-minute mark - prepare yourself!

## 🚀 Getting Started

### Play the Web Version

The game includes a WebGL build for browser play:

1. Navigate to the `BuildWeb` folder in the repository
2. Open `index.html` in your web browser
3. Enjoy the game!

> **Note**: For the best experience, use a modern browser like Chrome, Firefox, or Edge. The web build may require hosting on a local server or GitHub Pages to work properly due to browser security restrictions.

### Play in Unity

**Requirements:**
- Unity 2022.3.11f1 or compatible version
- Basic Unity knowledge

**Steps:**
1. Clone this repository:
   ```bash
   git clone https://github.com/JhonaMath/GameOff2023.git
   ```
2. Open the project in Unity
3. Open `Assets/Scenes/WorkingScene Art.unity` scene
4. Press Play in the Unity Editor

## 🎨 Game Design

### Enemy Types
The game features 5 distinct enemy types that appear as you progress:
- **Enemy Type 1-4**: Various dungeon creatures with different behaviors
- **Giant Enemy**: A larger, more formidable foe
- **Boss**: A multi-part boss encounter with its own epic soundtrack

### Progression System
- Experience-based leveling with scaling requirements
- 12 different stat categories to upgrade
- Maximum of 5 levels per stat category
- Strategic choice between two random upgrades per level
